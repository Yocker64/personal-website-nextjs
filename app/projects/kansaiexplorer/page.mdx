## 📍 Project Overview

This is the main page that displays all the information about the tours the company provides in the area of Kansai, Japan. The goal was to create an immersive experience that feels as serene and exciting as visiting Kyoto or Osaka.

**Key features include:**
- 🗺️ Interactive Map of Kansai
- 📅 Real-time Booking System
- 📱 Fully Responsive Mobile Design
- 🌙 Dark Mode support

## 💻 Code Highlight

One interesting challenge was handling the **Multilingual Support (i18n)**. Here is how I structured the locale switching context:

```tsx
// Example of clean code presentation
export const LocaleContext = createContext<LocaleContextType | null>(null);

export const useLocale = () => {
  const context = useContext(LocaleContext);
  if (!context) {
    throw new Error('useLocale must be used within a LocaleProvider');
  }
  return context;
};
```
